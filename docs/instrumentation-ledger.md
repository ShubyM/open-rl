# Instrumentation ledger

Every change that adds, removes or reshapes OpenRL telemetry gets one row here. A row says what the change records, which diagnostic questions it answers, what it costs, and what it measurably changed. The design these rows implement is [Design Doc 018: Run diagnostics](designs/018-run-diagnostics.md).

## How to add a row

1. Name the PR and branch.
2. **Adds**: the signal, record or endpoint, and where it is stored.
3. **Answers**: the questions it serves, from section 4.5 of the design.
4. **Cost**: bytes per record or step, series added, and backend lines added or removed (`python dev/diagnostics_budget.py`).
5. **Value**: a before and after you measured, such as payload bytes, a fact that now shows a replayed incident, or a cost drop. "Expected" is not a value; leave the cell as *pending* until it is measured.
