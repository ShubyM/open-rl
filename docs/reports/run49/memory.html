Qwen3.8-27B trainer memory on 8x H200

Measured 2026-09-10 on h200-vm with scripts/automodel_probe.py (Automodel worker) and the earlier Megatron probes. LoRA rank 32, one sequence per pass, peak GiB per GPU out of 139.8 usable. Sampler GPUs are separate, so the trainer has 4 GPUs unless noted.

Bottom line

  • Full 262,144-token context fits only with context parallelism. CP4 on the Automodel worker: 114.5 GiB allocated, 123.0 reserved, 136 s per forward+backward.
  • TP4/DP1 cannot get there on either backend. Megatron caps near 185k; Automodel caps near 130-140k.
  • The dominant term at long context is the activation stash of the residual stream. TP does not shard it; CP does.
  • Live run (run49, CP4): a 200,309-token trajectory backward peaked at 92.7 GiB, in line with the ladder.

Why the Automodel numbers moved

  • Per-submodule checkpointing. For its native Qwen3.5 model Automodel wraps self_attn, linear_attn and mlp separately and leaves the norms outside, so each layer stashes about four sequence tensors instead of one. That is the 2.47 GiB/1k tok row: 4x Megatron's per-layer stash, ceiling 47k. The worker turns that off and checkpoints groups of whole layers (OPEN_RL_AUTOMODEL_RECOMPUTE_NUM_LAYERS, default 4).
  • Group size trades stash for transient. Recompute cost is one extra forward regardless of group size. On TP4 the group's replicated GDN transient dominates, so k=2 beats k=4 (0.75 vs 0.94). On CP4 both terms are divided by 4, so k=4 is comfortable.
  • Automodel's GDN forward is heavier than Megatron's. Same layout and group size, TP4: 0.94 vs 0.58 GiB/1k tok. GVA head repeat of q/k, separate conv output, fp32 gate math.

Levers that did not work

  • Megatron CP: the GDN recurrent state is not carried across ranks in megatron-core 0.19.0; gradients are wrong past the first sequence chunk. Not a memory lever.
  • Megatron activation offload: mutually exclusive with recompute, so it materializes the full forward set before copying; OOMs at 160k, worse than recompute.
  • Megatron sequence parallel: asserted off by gdn.py.
  • Automodel TP with any group size: bounded by the replicated GDN transient, ~140k at best.
