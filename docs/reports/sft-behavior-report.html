The arc in one chart

1 · What SFT actually changes at step 0: almost no style, some survival

Across every generation, the SFT'd student's tool-calling style at step 0 is nearly indistinguishable from base — same tool mix, similar turn counts, similar parallelism. What v3 changed was episode survival: mean reward among surviving episodes was identical to v2's (0.635 vs 0.639), but four-to-five fewer episodes died. The entire 8-point baseline gain is fewer zeros, not better work.

2 · RL keeps what it rewards, discards what SFT taught

The behavior that actually moved scores — always write the deliverable — was re-learned by RL at full price in both lineages: run 14 went 34→46/50 in fifteen steps, exactly mirroring run 11's 38→50/50. SFT never pre-installed it, despite every kept teacher trace containing a written deliverable.

3 · The thinking-format defect (v2), and its repair (v3)

GLM marks a non-thinking turn by omitting reasoning; Qwen marks it with an empty <think> block — every legal Qwen turn carries think structure. The v2 converter mapped absence to absence, so ~47% of trained turns taught tag-free shapes the student never produces at inference. RL amplified that latent defect into run 14's late-run failure mode: stray </think> in visible content, turns ending mid-work with no tool call, episodes with nothing to grade (has_output 0.96 → 0.83). v3 renders thoughtless turns as <think>\n\n</think> — byte-identical to Qwen's own non-thinking prefill — and the canary has stayed at baseline since.

4 · The optimizer shock: how run 15 lost 13 points without getting worse

Mechanism: warm-start RL begins with fresh Adam at full lr 2e-4, no warmup, no KL anchor (kl_penalty_coef=0). SFT sharpens the policy exactly where it trained — think structure and stopping tokens — and sharp distributions are where importance ratios explode. optim/kl_sample_train grew to ~20× baseline with rising grad norms: the classic drift loop where each update invalidates the data the next gradient is computed from. The damage scaled with altitude — the best warm start (57.9) produced the worst collapse (45), while run 14's mediocre start shrugged its dip off. Every warm-started run dipped at b5; no RL-only run ever did.

Verdict and the one experiment left

What SFT provably transfers: episode survival (format legality) and a mild, temporary style prior. What it does not transfer: the reward-relevant disciplines RL learns on its own. What it risks: a sharpened policy that full-lr RL destroys in five steps. The decisive A/B is queued: relaunch the identical v3 snapshot at learning_rate=1e-4, abort early if kl_sample_train exceeds ~3–5× baseline by step 3. If b5 holds ≥56, the project has its best-ever trajectory; if it collapses at half lr, warm-starting is closed with clean evidence and RL-only stands as the answer.
