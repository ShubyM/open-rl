Step 0 and step 15

Task 11 asks for a governance diligence memo for Hargrove Capital’s proposed acquisition of Terravox Systems. Both runs receive the same documents. The point here is whether the model just summarizes them or answers the buyer’s actual deal questions.

Assignment
Review Terravox’s governance documents for a $485 million reverse triangular merger and prepare a diligence memo for buyer’s counsel.
Inputs
Counsel’s directive email, certificate of incorporation, bylaws, stockholders’ agreement, voting agreement, registration rights agreement, and board minutes.
Expected output
A 15–20 page Word memo with ten requested diligence areas, provision citations, action items, a consent matrix, and Critical / Significant / Moderate issue labels. There are 59 rubric items.

It also adds the action list, consent matrix, and severity labels. It gets 42 of 59 rubric items.

2. Run trajectory

Tool use and document coverage

Document coverage is how much of the requested deliverable the grader found. A document-workflow turn contains writing, conversion, validation, packaging, or direct Python Word-document work. Each point averages 48 training rollouts.

Coverage goes from 73.5% to 85.0%. Document-workflow turns go from 5.85 to 3.58 per rollout. The middle steps move around, but later rollouts generally cover more of the requested document with fewer build and repair turns.
